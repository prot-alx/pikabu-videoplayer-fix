# Pikabu Video Player Fix
По умолчанию видеоплеер пикабу ведет себя странно, паузится при переключении на другие вкладки, пролистывании ленты. Если такое поведение не устраивает, то этот скрипт для вас! 

Скрипт для Tampermonkey, убирающий автопаузы видеоплеера на сайте Pikabu при перемотке ленты или переключении вкладок

## Возможности
- Исправляет авто-паузу видео
- Корректно обрабатывает клики и нажатия пробела
- Синхронизирует UI с состоянием видео
- Останавливает другие видео при воспроизведении нового
- Позволяет видео продолжать воспроизведение при переключении вкладок

## Установка
1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера
2. [Кликните здесь](https://github.com/prot-alx/pikabu-videoplayer-fix/raw/main/pikabu-videoplayer-fix.user.js), чтобы установить скрипт (либо скопируйте содержимое в tampermonkey)
3. Подтвердите установку в открывшемся окне Tampermonkey
